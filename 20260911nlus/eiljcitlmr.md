# 医术精湛品德优 锦旗感谢寄真情

> 更新时间：2026-09-11 (UTC+8)

“金奖银奖不如百姓夸奖，金杯银杯不如百姓口碑”。一面熠熠生辉的锦旗,一封饱含深情的感谢信,是患者对医护人员仁心仁术的最大肯定,承载着患者的信任和感激,展示出一份浓浓的医患深情。
       近日南阳市中心医院胸外科食管病区收到患者谷女士送来感谢锦旗，上面写着烫金的“医术精湛品德优，服务热忱如亲人”、“白衣天使照顾周，精心护理暖心人”字样，谷女士再三感谢南阳市中心医院胸外科食管病区全体医护人员对自己的精心治疗及护理，激动之情溢于言表。

       今年71岁的谷女士，因食管梗阻进食不畅数日，于9月13日入住南阳市中心医院胸外科食管病区，检查诊断为“胸中下段食管恶性肿瘤， 2型糖尿病”。由于进食不畅，谷女士情绪非常低落，家属万分着急。入院后科主任李伟、副主任林涛、主管医生卢万里，结合各项检查结果决定为谷女士进行手术治疗。谷女士在得知需要手术的消息后，担心手术的效果、术后的后遗症等，产生了畏难情绪，极度沮丧，李伟主任，林涛主任及卢万里医师主动来到谷女士的病床前为她做心理疏导，从专业的角度剖析病情，使谷女土原本紧张的神经渐渐放松。       手术当天，时祥音护士长为了缓解谷女士的紧张，一早到病房密切关注她术前的心理状况，并及时给予疏导，“当手术室护士来接我去手术室时，时护士长一句‘没事的！姨，不要怕，有我们在，手术中我们的医生护士都在你的身边，没必要担心。’就这简简单单的一句话，对我来说是多么大的鼓舞，我真的很感激。“谷阿姨激动地说，并不停地夸南阳市中心医院胸外科食管病区的医护人员温柔、可亲、可敬，考虑又是非常细致全面。       谷女士表示，在监护室的日子，护士们都很有礼貌，给了她亲人一般的温暖，不仅督促她做康复锻炼，还及时给予心理疏导，安抚她忧虑又恐惧的心，使术后效果及伤口愈合非常理想。
       每一面锦旗的背后都是患者的真情流露，每一次真诚的感谢都给予全体医护人员无尽的力量。在行医路上得到患者的认可，就是医务人员务实求真的动力。收到锦旗后，南阳市胸外科食管病区李伟主任、林涛主任、主管医师卢万里及时祥音护士长表示，将继续秉承专业、高质的服务理念，全心全意为人民群众身体健康服务。
